# ADR 0003: jose (runtime dependency, api/)

Status: accepted for M5a. Date: 2026-11-13.

**Decision.** Use `jose` to verify HS256 JWTs. The secret comes from the `JWT_SECRET` environment variable.

**Why.** Hand-rolled token checks are a common source of bypasses (accepting `alg: none`, skipping expiry). `jose` has no dependencies, pins the accepted algorithm on verify, and checks `exp`.

**Alternatives.** `jsonwebtoken` (larger tree, more legacy options); static API keys in a table (needs a keys table and hashing, weaker for forged-auth tests).

**Risks.** A shared HS256 secret means anyone holding it can mint any role. Acceptable for M5a (read-only, synthetic data). Real identity (an IdP, asymmetric keys, rotation) is a later decision and out of scope here.
